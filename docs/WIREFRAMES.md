```text
+------------------------------------------------------+
| Menu lateral | Indicadores de vendas, clientes,      |
|              | estoque baixo e vendas recentes       |

```

## Cadastros

```text
+------------------------------------------------------+
| Titulo da tela                         [Novo Item]    |
|                                                      |
| Tabela: codigo/nome/documento/status/acoes           |
|                                                      |
| Modal: campos do cadastro + botoes cancelar/salvar   |
+------------------------------------------------------+
```

## Compras

```text
+------------------------------------------------------+
| Compras                               [Nova Compra]   |
| Pedido | NF | Fornecedor | Total | Status | Pagto     |
|                                                      |
| Modal: fornecedor, pedido, NF, itens, desconto, total |
+------------------------------------------------------+
```

## Vendas

```text
+------------------------------------------------------+
| Vendas                                  [Nova Venda]  |
| ID | Data | Cliente | Total | Pagamento | Comprovante |
|                                                      |
| Modal: cliente, itens, desconto, total               |
| Modal comprovante: itens + total + imprimir/PDF      |
+------------------------------------------------------+
```

## Estoque

```text
+------------------------------------------------------+
| Estoque                                              |

```

## Financeiro

```text
+------------------------------------------------------+
| Financeiro                            [Lancamento]    |
| Cards: receitas, despesas, saldo, pagar, receber      |
| Contas a receber | baixar/estornar                    |

+------------------------------------------------------+
```
