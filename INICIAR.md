# Como iniciar rapido

Execute o arquivo `.\start-dev.bat` na raiz do projeto.

Ele abre duas janelas:
- Backend FastAPI: http://localhost:8000
- Frontend React: http://localhost:3000

Antes de iniciar, confirme que o PostgreSQL esta rodando e que existe o banco `ERP_Mercearia` com usuario `postgres` e senha `1234`, conforme `app/backend/.env`.

Para parar o projeto, feche as duas janelas do PowerShell que foram abertas.
